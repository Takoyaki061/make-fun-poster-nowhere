# CINDERLOOM — The Poster for a Place That Isn't There

A travel poster for **Cinderloom**, an invented place: a lighthouse built
of stacked glass bricks that never had a sea. It stands on a desert of
black sand and sweeps its ember beam across the dunes every night, while
a low sun sinks behind the horizon. You arrive restless and leave quiet —
as if someone finally turned off a switch.

## How to run

```sh
python3 main.py
```

Requires Python 3.13 and Pillow. Writes `entry.png` (1024x1024 PNG) to
`$MAKEFUN_OUTPUT_DIR` (default `/output`). The output is deterministic:
re-running produces byte-identical output.

## The poster

- Palette: ink night `#101820`, ember `#E4572E`, bone `#F1E9DA`.
- One landmark: the glass-brick lighthouse, its beam landing in a pool
  of light on the black sand.
- The place's name is set in large letterspaced capitals across the top,
  with an ember rule beneath it. No other copy.
